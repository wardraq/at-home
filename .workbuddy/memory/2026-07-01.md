# 2026-07-01 工作日志

## 服务端协议设计讨论
- 确定多用户模型：服务端维护用户列表，每台手机独立 userId（身份+认证合一）
- 去掉验证码：userId 是长随机串，比 6位 code 安全得多，QR 码即安全通道
- 安全方向修正：客户端验证服务端（手机确认服务器身份），而非服务端验证客户端
- 握手协议：手机发 userId，服务端返回 serverId + sessionToken；手机验证 serverId 对暗号
- sessionToken TTL 7天 + 断连重握手
- 按用户隔离存储：Photos Backup/{userName}/YYYY/MM/
- 用户名创建后不可改
- 安全评估：HTTP 明文下握手验一次 serverId 即达安全上限，每次验 serverId 也无法防 MITM
- 更新设计文档 docs/设计文档.md（三、四、六、七、九、十节）
